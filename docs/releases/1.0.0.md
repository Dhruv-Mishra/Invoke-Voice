# Invoke 1.0.0

**From Voice to Agency**

The first stable Invoke release brings voice conversation, delegated agent sessions, and task outcomes into one local-first Windows desktop experience.

## Highlights

- Invoke branding, app icon, and Windows installer identity.
- Agency connection checks on entry, automatic owned-proxy startup, and concise setup guidance without silently enabling work-data access.
- Final-response publication after tool receipts for text chat and local/hybrid voice, instead of repeated intermediate completion claims.
- Persistent same-session follow-up queues with failure recovery and deduplicated outcome announcements.
- A heading-only notification inbox with clear/read actions and improved spacing.
- Red active-call hang-up control and an optional connected-call greeting.
- Voice commands for theme selection, inbox management, and spoken updates.
- Proxy-aware desktop updates with a public stable-manifest fallback and mandatory installer checksums.
- Patched Sharp and Electron build tooling; clean runtime and development dependency audits, with compact regression-tested tool contracts.

## Downloads

Choose **Invoke-Setup-1.0.0.exe** (Bundled) or **Invoke-Setup-1.0.0-Online.exe** (smaller installer). Bundled includes the Python dependency archive; Online downloads the identical verified archive during setup. Both still need selected voice models and native runtimes. The separate dependency archive supports approved offline provisioning.

SHA-256 sidecars accompany installers and the dependency archive. `invoke-update.json` is the stable updater fallback manifest. Existing beta installers need a manual install of Invoke; beta updater compatibility is not provided.

## Important Notes

- Windows x64; installers are unsigned. Follow SmartScreen and organizational policy.
- Agency/Copilot sign-in, provider access, and enterprise source permissions are not bundled.
- A verified tool catalog does not establish tenant identity or access to a specific source. Work-data research remains opt-in.
- User data continues under `%LOCALAPPDATA%\VoiceSupervisor`; uninstall does not erase it.
- Supplied theme artwork and audio remain included at the project owner's request, with unverified redistribution rights. Character-inspired themes are unofficial and not endorsed.
- Physical microphone/speaker performance, clean-machine provisioning, and live provider quality require target-device validation. No enterprise certification or latency guarantee is implied.
