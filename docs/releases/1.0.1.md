# Invoke 1.0.1

## Faster Local Responses

- Restored incremental local replies so speech can begin before the full answer completes.
- Matched the warm-up prompt's tool schema to live voice calls for prefix-cache reuse.
- Kept thinking disabled and the existing compact tool set; tightened guidance to use task titles, not internal IDs.
- Made default Kokoro threads CPU-aware and batched streamed chat rendering per animation frame. Saved overrides are preserved.

## Teams And Calendar

- Teams MCP connections start automatically when Agency is installed. Private research remains opt-in.
- Sign in to Agency with your work account, then open Settings > Integrations > Private work sources, choose Read-only, and Save config. Use Check connections to verify tool catalogs.
- Calendar now opens Outlook or requests today's schedule through a read-only Agency task. Outlook and Teams share the work calendar. Opening the tab does not read private data.
- Questions and answers use cloud services, are saved, and may be spoken. Catalog readiness is not proof of work-account authorization.

## Desktop Polish

- Restored Copilot artwork for the app, sidebar, Windows executable and installer.
- Native window controls follow the active theme; the notification bell stays centered with or without an unread badge.
- Simplified long option menus, normalized voice-popup surfaces and spacing, and preserved settings focus during refresh.

## Model Update And Data Reset

- Switched the managed default to Ling APEX-I Quality (5.77 GB), pinned and hash-verified. The publisher rates it highest for accuracy; it is slightly smaller than Balanced, but larger than Compact and may be slower on memory-constrained devices. No independent variant benchmark is claimed.
- Previously consented, verified managed Compact installations automatically download Quality on startup. Custom paths and fresh-install consent are preserved. The old model remains on disk, including if the download fails; the saved selection updates after successful startup.
- Kept hybrid thinking off: additional reasoning tokens delay the first spoken answer. The existing tool-capable coordinator remains intact.
- Added a red **Settings > Application data > Clear application data** action in installed desktop builds. Confirmation defaults to Cancel. Deletion stops services, clears app-owned data and browser storage, then restarts with fresh setup required.
- Reset permanently removes keys, history, managed worktrees including uncommitted changes, models, runtimes and caches. External repositories/custom files, source configuration and Agency credentials/session storage are preserved. It does not uninstall Invoke or erase cloud records.

## Validation And Limits

Deterministic tests verify first text before stream completion, thinking-off requests, matching warm-up tools, managed migration/failure retention, reset boundaries and confirmation, read-only calendar dispatch, consent gating, and responsive Electron interactions. Real local-model latency, physical audio, and private calendar authorization still depend on the target machine and account; no all-hardware speedup is claimed. Local output now streams without prose rewriting, so already-streamed text may remain visible or audible if a later error occurs. Installers remain unsigned.

Both Bundled and Online Windows editions include the same application. Voice models and native runtimes still download during consented setup.
