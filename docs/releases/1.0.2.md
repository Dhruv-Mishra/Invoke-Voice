# Invoke 1.0.2

## Voice Reliability

- Removed per-tool cloud response triggers that could produce repeated deletion confirmations. Gemini Live waits for the tool batch; OpenAI Realtime requests one continuation after all completed tool results.
- Persist accepted task announcements using the existing inbox read state. Failed-task announcements no longer replay after reconnecting or restarting. Busy sessions retain unread announcements; interrupted accepted announcements remain in the inbox without automatic replay.
- Kept the end-call tool and removed the extra confirmation guidance.
- Increased the tool budget to eight rounds plus a tool-disabled final answer. Tool arguments are validated before execution, repeated mutations reuse receipts, and status reads remain fresh.
- Preserved incremental local responses, thinking-off requests, and concurrent independent tool execution. No model-prose rewriting or example-specific response rules were added.

## Task Cancellation

- Added Stop controls on active task cards and task details, plus the `cancel_work` voice/chat tool.
- Cancellation stops the selected worker and discards queued follow-ups. Completed changes, task history, and worktrees are retained; cancellation is not rollback.
- Late worker results cannot turn cancelled work into success. Prepared tasks can be continued explicitly after cleanup finishes.

## Agency And Private Sources

- Agency coding tasks now use task-local profiles, avoiding invalid ambient MCP server names without editing global configuration. Explicit Invoke and repository MCP connections remain; global MCPs and plugins are not implicitly inherited.
- Report worker startup once per process instead of once per model turn. Repeated source checks still represent actual tool activity.
- Moved Private work sources to Settings > Integrations with its own Save access control and a direct Agency link. Permission changes apply immediately to new research tasks and follow-ups; already-running tasks retain their launch-time permissions.
- Clarified that Invoke starts its own Teams/WorkIQ/Bluebird HTTP proxies; installing Agency alone does not start them. Connection checks verify catalogs without reading business content or changing consent.

## Validation And Limits

Regression coverage includes both cloud tool protocols, interrupted tool batches, persisted notification acknowledgment across voice sessions, cancellation of an owned Windows process tree, queued work, and responsive browser controls. Live Agency coding and restricted research checks passed with same-session follow-ups and consent revoke/restore.

Cloud speech protocol tests use deterministic provider fixtures, not a physical microphone or paid live voice session. No local-model accuracy or latency benchmark is claimed. Catalog readiness does not prove tenant or content authorization. Both Windows editions contain the same fixes; installers remain unsigned.
