# Invoke 1.0.3

## Desktop Preferences

- Persist appearance, wallpaper, volume, voice route, and coding backend preferences in the desktop data folder so they survive restarts even though Invoke uses a new loopback port each time.
- Preserve explicit Agency or Copilot selections while keeping Agency as the fresh-install default.
- Keep browser-source runs on their existing per-origin storage path; desktop persistence remains allowlisted, bounded, and removed by Clear application data.

## Settings Reliability

- Preserve unsaved settings while background state refreshes occur, prompt before leaving with pending edits, and retain drafts when a save fails.
- Send only changed configuration fields and report restart requirements against effective startup defaults.
- Simplify inactivity choices to Off, 30 seconds, or 1 minute while retaining existing custom values. Active speech and generation continue to defer automatic call ending.
- Clear application data now closes Invoke after deletion instead of attempting an automatic relaunch; reopen the app to begin fresh setup.

## Setup And Voice Fixes

- Make private-workspace initialization safe to repeat when an incomplete `.git` directory already exists, without changing external repository behavior.
- Install the verified offline Python dependency pack with isolated bundled pip, avoiding an incompatibility between uv and the compressed release wheels while preserving hash checks and network isolation.
- Keep the selected local speech recognizer label accurate and remove stale voice-session state during shutdown.
- Normalize Baymax cue volume with the other themes while preserving the global volume and mute controls.

## Validation And Limits

Regression coverage includes desktop preference persistence across port changes, settings drafts and save failures, repeated private-workspace initialization, verified offline dependency installation, voice cleanup, and responsive Electron views. Installers remain unsigned. Physical microphone and speaker behavior, private work-account authorization, and first-time downloads still depend on the target machine and account.
