# Invoke 1.0.4

## Local Model Reliability

- Use constrained JSON-schema responses for local tool routing so complete tool batches are validated before execution and only finished answers reach chat or speech.
- Preserve the full system and tool contract while fitting conversation history to the configured context window, and fail clearly when essential context cannot fit.
- Disable llama.cpp context shifting for managed local servers to keep prompt-cache and context-budget behavior predictable.
- Keep successful mutations deduplicated while allowing failed mutations to be retried.

## Work And Research Controls

- Stop app-owned active work before deleting its history, wait for the worker to settle, and leave project files untouched. Work not owned by Invoke remains protected.
- Include task titles in status responses and expose only actions that are currently available.
- Run Agency research with low reasoning effort, bounded inactivity and total deadlines, and concise source progress that does not expose private arguments or content.
- Keep delegated answers brief by default while allowing detailed responses when explicitly requested.

## Setup Progress

- Show estimated download time from the current transfer rate alongside progress and byte counts.
- Reset estimates between files, retries, and install stages, and hide stale estimates when a transfer stalls or enters verification.

## Validation And Limits

Regression coverage includes structured local tool batches, context pressure, retry and deletion behavior, Agency research deadlines, and setup progress estimates. Installers remain unsigned. Physical microphone and speaker behavior, private work-account authorization, and live inference with every supported local model still depend on the target machine and account.
