# Invoke 1.0.5

## Local Speech Reliability

- Increase the default hands-free pause threshold to 1.4 seconds for both local recognizers so ordinary mid-sentence pauses are less likely to submit early.
- Keep Whisper push-to-talk audio in one explicit segment until release, including pauses while the button remains held.
- Ignore late partials, duplicate recognition finals, superseded transcripts, and interrupted announcement replays after a turn has been accepted or cancelled.
- Expose the Whisper and Moonshine pause thresholds in Settings, with saved values taking effect after restart.

## Local Routing Controls

- Bound local text and voice turns to three tool rounds and six executed calls, followed by a tool-free answer. Hosted providers retain their existing eight-round allowance.
- Prevent a local read intent from escalating into changes after execution begins, and stop completed reads without unnecessary polling.
- Reuse successful local call receipts across batches and rounds while allowing reads to refresh after a successful change and failed calls to retry within the remaining budget.
- Ask for clarification when a task search is ambiguous instead of continuing speculative generation.

## Work Model And Diagnostics

- Preserve explicit coding-model selections when creating work and resolve the legacy `default` value to the selected model. Resumed legacy sessions no longer pass `--model default` to Agency or Copilot.
- Allow clearing a legacy local GGUF environment path in Settings to return to managed Ling after restart.
- Expand the local benchmark with deterministic routing scenarios, configurable generation seeds, optional native tool comparison, and nonzero exit status when any scenario fails.

## Validation And Limits

Regression coverage includes speech pause handling, push-to-talk ordering, duplicate-final suppression, local round and call budgets, read/change isolation, receipt reuse, model propagation, and settings overrides. The measured Whisper Small INT8 run recognized six clean synthetic English samples, while the Ling Quality acceptance run passed eight of eleven routing cases; external delegation, deletion lookup, and an explicit worker follow-up remain known failures. Installers remain unsigned, and physical microphones, noisy speech, accents, private work authorization, and target-device performance were not independently validated.
