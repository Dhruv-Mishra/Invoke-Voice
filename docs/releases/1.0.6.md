# Invoke 1.0.6

## Managed Local Model

- Use Google's official Gemma 4 E2B IT QAT Q4_0 GGUF as the managed local language model for new setups.
- Upgrade previously consented, verified managed Ling Compact and Quality installations without changing fresh-install consent or explicit custom model paths.
- Keep existing model files in place and switch the saved selection only after Gemma downloads, verifies, and starts successfully.
- Preserve the `ling-local` endpoint alias for compatibility with existing configuration.

## Faster Whisper Responses

- Start one provisional Whisper decode after 480 ms of hands-free silence and reuse it only when the accepted endpoint contains identical audio and utterance metadata.
- Cancel provisional reuse when speech resumes, and keep push-to-talk and busy-decoder behavior on the normal final-decode path.
- Allow early decoding to be disabled in Settings or with `WHISPER_PREDECODE_MS=0`; changes take effect after restart.
- Add deterministic scheduling benchmarks and worker regressions for resumed speech, duplicate finals, cancellation, short utterances, and disabled early decoding.

## Validation And Limits

Regression coverage includes managed-model migration and rollback behavior, structured local routing, Whisper provisional scheduling, final-transcript uniqueness, and settings persistence. Gemma passed the expanded 21-case synthetic tool gate after API refinements, and the measured Whisper scheduling run reduced short hands-free recognition latency by about 0.9 seconds on the test workstation. These measurements do not guarantee performance across requests or hardware. Installers remain unsigned, and physical microphones, noisy or multilingual speech, target-device setup, and every live model route were not independently validated.
