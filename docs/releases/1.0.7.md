# Invoke 1.0.7

## Direct Voice Work Tools

- Add opt-in direct voice access to approved read-only WorkIQ, Teams, calendar, people, and Microsoft Learn tools without creating an Agency task.
- Discover tool schemas only when requested by the voice model and keep write operations, delegated `ask` calls, and unknown tools blocked.
- Require both private-work access and direct voice access to be enabled explicitly, preserving the existing default with no enterprise data access.
- Bound discovered schemas and compact local context without exposing internal routing identifiers in spoken summaries.

## Local Voice Setup And Recovery

- Treat installed local speech components as runtime initialization instead of repeating first-time installation consent and download estimates.
- Restore missing setup metadata for verified installations and make retry restart installed voice runtimes without reinstalling them.
- Allow Kokoro up to three minutes for cold initialization, including warm-up, while reusing a ready worker and cleaning up failed or cancelled starts.
- Clarify setup and settings states with `Initializing` and `Retry voice`, improved restart notices, and more consistent compact layouts.

## Validation And Limits

Regression coverage includes direct-tool discovery and access controls, installed-runtime recovery, setup state restoration, Kokoro startup lifecycle, and responsive settings layouts. Direct access remains read-only and opt-in, and catalog readiness does not prove authorization to read a particular account or source. Installers remain unsigned; physical microphones, target-device first-time setup, private enterprise content, and every live model route were not independently validated.
