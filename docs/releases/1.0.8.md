# Invoke 1.0.8

## Experimental Local Routing

- Make Raw-scored the default local routing mode when no saved or environment selection exists; saved Regular mode and explicit `LOCAL_ROUTER=off` remain respected.
- Add a live **Local routing** setting that switches subsequent local text and voice turns between Regular and Raw-scored without reconnecting the call or restarting the model.
- Keep hosted routing unchanged and preserve existing schema validation, consent checks, call budgets, receipt reuse, cancellation, and grounded final summaries.
- Retain diagnostic shadow mode and confidence thresholds for controlled evaluation while the user-facing Raw-scored setting uses the measured permissive policy.

## Local Reasoning And Work Reads

- Bound local routing reasoning to 256 tokens by default and use zero reasoning tokens for tool-free summaries; expose the routing budget in local performance settings.
- Avoid an unnecessary routing generation after completed tool work while preserving dependent rounds, retries, and multi-step actions.
- Consolidate default private research and direct voice reads on approved WorkIQ retrieval, schema, and fetch operations, with source-aware email, Teams, calendar, files, and people search.
- Keep expanded Microsoft 365 catalogs optional and continue blocking WorkIQ `ask`, writes, shell, filesystem, and unrecognized tools from read-only paths.

## Validation And Limits

Raw-scored routing is experimental and did not pass the measured accuracy or safety gates. In the 54-case synthetic Jevify workflow, Gemma Raw-scored passed 36 cases (66.7%) versus 41 (75.9%) for the Regular planner; observed failures included wrong actions, named-task misrouting, multi-action collapse, and following an injected output label. The same evaluation showed substantial workstation latency savings, but it is not a production success rate or target-device guarantee. Use **Settings > Keys and config > Local performance > Local routing > Regular** to restore the regular planner immediately. Installers remain unsigned, and physical audio, private enterprise search quality, target-device setup, and every live model route were not independently validated.
